# AGLX-Encryptor# 🔐 AGLX Encryptor

**AGLX Encryptor** is a Windows application developed by **Gaetano Alabrese** for protecting files through encryption and cryptographic verification.

The application is designed to provide a simple and accessible interface while combining file encryption, integrity verification and timestamping capabilities.

## 🚀 Available on Microsoft Store

[**Get AGLX Encryptor on Microsoft Store**](https://apps.microsoft.com/store/detail/9MW2RPVS630T)

## ✨ Features

* 🔐 **RSA 2048 encryption**
* 🔑 Secure file protection
* 🧾 **SHA-256** integrity verification
* 📦 Proprietary `.aglx` encrypted file format
* ⏱️ **RFC 3161 timestamping**
* 📄 Timestamp and verification reports in PDF format
* 🖥️ Designed for Windows
* 🆓 Free version available

## 🛡️ Security

AGLX Encryptor combines encryption and cryptographic hashing to help protect files and verify their integrity.

The application uses **RSA 2048** and **SHA-256** cryptographic technologies together with RFC 3161 timestamping for document and file verification.

## 🆓 Free Version

The current version of AGLX Encryptor is available as a **free application** through the Microsoft Store.

The Free version provides the core encryption and verification functionality.
